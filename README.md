# Quick Map — releases

Публічні збірки десктопного застосунку **Quick Map** та маніфести автооновлення.

Вихідний код тут не публікується — цей репозиторій містить лише артефакти збірки.

## Завантажити

Найсвіжіша версія: **[Releases](https://github.com/3R-Tools/quick-map-releases/releases/latest)**

| Платформа | Файл |
|---|---|
| macOS (Apple Silicon) | `QuickMap-<версія>-mac-arm64.dmg` |
| macOS (Intel) | `QuickMap-<версія>-mac-x64.dmg` |
| Windows | `QuickMap-<версія>-win-x64.exe` |
| Linux | `QuickMap-<версія>-linux-x86_64.AppImage` або `.deb` |
| Офлайн веб-версія | `quick-map-offline-<версія>.zip` |

## Автооновлення

Застосунок перевіряє оновлення сам і оновлюється з цих релізів.
Файли `latest-mac.yml`, `latest.yml`, `latest-linux.yml` потрібні для роботи
`electron-updater` — не видаляйте їх з релізу.

## Сторінка завантажень (Vercel)

`index.html` розгортається на Vercel як статика з двома функціями:

- [`middleware.js`](middleware.js) — Basic Auth на весь сайт, виконується до віддачі HTML;
- [`api/releases.js`](api/releases.js) — список релізів; посилання на файли видаються
  підписаними (HMAC-SHA256) і живуть 15 хвилин;
- [`api/dl.js`](api/dl.js) — перевіряє підпис і віддає `302` на GitHub.

Environment variables проєкту:

| Змінна | Обов'язкова | Призначення |
|---|---|---|
| `SITE_PASSWORD` | так | пароль до сторінки; без неї сайт віддає `503` |
| `DL_SECRET` | так | ключ для підпису посилань (довгий випадковий рядок) |
| `SITE_USER` | ні | логін, типово `quickmap` |
| `LINK_TTL` | ні | строк життя посилання в секундах, типово `900` |
| `GITHUB_REPO` | ні | типово `3R-Tools/quick-map-releases` |
| `GITHUB_TOKEN` | ні | вмикає режим приватного репозиторію |

Поки репозиторій публічний, підписані посилання не закривають доступ до файлів:
той самий артефакт лишається доступним за прямим URL релізу на GitHub. Щоб доступ
став реальним, репозиторій треба зробити приватним і задати `GITHUB_TOKEN` —
тоді `api/dl.js` бере короткоживучий підписаний URL у GitHub API. Автооновлення
застосунку при цьому доведеться перевести з `provider: github` на `generic`.
